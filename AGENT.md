# Памятка для работы с проектом

## Текущее устройство

- Основная реализация игры находится в `langflow/custom_components/my_components/` и выполняется внутри Langflow.
- `langflow/docker-compose.yml` запускает Langflow и PostgreSQL, подключает каталог компонентов и хранит состояние в томах Docker.
- `rag_docs_gorod_N/` содержит читаемые материалы сценария; `rag.py` содержит встроенный корпус с векторами для работы узла RAG.
- Готового JSON-экспорта графа, пакета `negotiation_mvp` и прежних тестов сейчас нет.
- `langflow/smoke_run.py`, `component_smoke.py` и `build_demo_flow.py` зависят от удалённых файлов. Не указывайте их как рабочие команды без восстановления зависимостей.

## Как вносить изменения

- Сверяйте документацию с файлами в рабочей копии и с фактическими входами и выходами компонентов.
- Не восстанавливайте удалённые файлы и не меняйте пользовательские правки без прямой необходимости для задачи.
- При изменении Compose проверяйте `docker compose -f langflow/docker-compose.yml config --quiet` и `git diff --check`.
- Если меняется поведение компонентов, обновляйте соответствующий раздел README и описывайте ограничения проверки.
