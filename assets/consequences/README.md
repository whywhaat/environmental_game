# Иллюстрации исходов для «Вестника города N»

Картинки готовятся заранее и выбираются по id исхода. Газета состоит из иллюстрации и отдельного читаемого текста в одном сообщении Langflow. Суммы, сроки и выводы добавляет код; их не нужно рисовать на картинках.

По требованию от 03.11.2026 текст газеты выдаётся одним связным абзацем: название исхода, описание последствий, решение по протоколу, деньги, сроки и показатели города. Заголовки, списки и таблицы в ответе не используются; текст можно выделить и скопировать. В итоговом тексте нет ссылок на учебник, сравнений с эталоном, пояснений об устройстве модели и оговорки об учебной гипотезе. Промпт «Вестника» требует тот же формат. Источники правил и допущения доступны в отдельном подробном отчёте.

## Общий вид

- PNG или WebP, горизонтальный формат 3:2, например 1536 × 1024. JPEG тоже поддерживается.
- Одинаковые стиль, палитра, город и основные здания во всех изображениях. Первый удачный рисунок используйте как референс для остальных.
- Редакционная иллюстрация к учебной газете: условный российский промышленный город, река, комбинат и очистные сооружения.
- Без надписей, цифр, логотипов, рамки газетной страницы и мелкого текста на экранах.
- Иллюстрация передаёт тему исхода. Конкретные сроки, затраты и состояние города берутся из текста партии.
- Не изображайте болезни, погибших людей, банкротство или закрытие комбината как установленное последствие.

Готов полный набор **10/10**: по одному PNG 1536 × 1024 для каждого исхода из таблицы ниже. Если в конкретном Langflow поле изображения ещё не заполнено, газета выводится текстом.

Готовый референс: [«Открытая река»](open_river.png), 1536 × 1024. Иллюстрация предоставлена пользователем 30.10.2026 и сохранена без изменений. Для остальных исходов используйте тот же город, ракурс и стиль, меняя состояние очистных, реки и характер взаимодействия участников в соответствии с темой.

03.11.2026 встроенным `image_gen` созданы «Недострой» и «Каждый сам за себя», обе PNG 1536 × 1024, с «Открытой рекой» как референсом. В первом изображении показаны незавершённые очистные, во втором — разобщённые группы участников и старая инфраструктура.

04.11.2026 тем же встроенным `image_gen` отдельно созданы ещё семь PNG: «Застой», «Компромисс», «Решили без жителей», «Долгострой», «Холдинг заплатил за всех», «Город заплатил за всех», «Чистая вода, закрытые данные». Общий референс — исходная «Открытая река»; три прежних файла сохранены без изменений. [Полные промпты обеих генераций](prompts.md) сохранены. Долгострой показывает завершённые после ожидания очистные; Застой — старую нереконструированную инфраструктуру. Финансовые сюжеты показывают нагрузку на ответственных участников, без чисел и утверждений о банкротстве.

Это рекомендуемые имена для организации набора. Код выбирает изображение по полю загрузки, поэтому сами файлы можно назвать иначе. Для каждого исхода загружается одно изображение.

## Подключение в Langflow

1. Импортируйте актуальный `langflow/Negotiation_MVP_with_consequences.json` или используйте локальную копию игры.
2. В узле «Модель последствий» загрузите готовые файлы в соответствующие поля «Картинка: Открытая река», «Картинка: Недострой» и т. д. Важно именно загрузить файлы: путь к картинке на вашем компьютере сам по себе не делает её доступной браузеру или другому серверу.
3. Выход «Газета» подключён к ChatOutput последствий. Он возвращает готовый текст и вложение выбранного исхода. Выходы «Отчёт», «Прогноз» и «Промпт «Вестника»» остаются доступными отдельно.

Langflow автоматически добавляет к загруженному имени префикс времени; переименовывать файл после загрузки не нужно. Если поле выбранного исхода пустое, выводится текст без вложения.

Поля иллюстраций используют загрузку в файлы текущего flow (`temp_file=True`). Режим общей библиотеки здесь не подходит: Playground не находит загруженный через flow API файл в общей библиотеке и при открытии узла очищает его привязку.

Изображение добавляется в `content_blocks` сообщения как rich image: AI-ответы установленного Playground не отображают одно лишь поле `files`. Пиксели передаются без изменений в base64 внутри группы, которую сохраняет v1 API; текст остаётся отдельным читаемым текстом сообщения. Ключ в `files` также сохраняется для скачивания и других клиентов. Структурированный прогноз модели не содержит бинарных изображений.

Сам JSON flow не переносит загруженные изображения на другой сервер. При смене Langflow-сервера их нужно загрузить заново. На своей платформе выбирайте ресурс по тому же `outcome.id`; готовый текст доступен в `forecast(...)["herald_text"]`, а структурированные данные прогноза сохраняются отдельно.
