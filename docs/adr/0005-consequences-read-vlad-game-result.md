# Модель последствий читает итог игры Влада, а не ядра переговоров

Модель последствий принимает только выход оркестратора игры Влада: взносы и голоса по именам игроков, условия протокола с владельцами, `consensus_reached`, профили игроков. Итог ядра `negotiation_mvp` (игра Олега, на котором модель была сделана сначала) больше не читается. Команда 23.10 выбрала основной игру Влада, а его оркестратор ядро не использует; в его протоколе нет ответственных за компоненты сметы, их место заняли условия протокола, поэтому правила исполнения переписаны под владельцев условий, а не только адаптер.

## Рассмотренные варианты

- Два адаптера к одному Протоколу: формат Олега больше не идёт в основном flow, а правила про ответственных за компоненты всё равно не переносятся на игру Влада — пришлось бы держать и тестировать две модели исполнения.
