# Модель последствий — пакет в корне репо, Langflow-компонент только импортирует его

Ядро модели последствий лежит отдельным пакетом на чистом Python в корне репо, а Langflow-компонент — тонкая обёртка, которая его импортирует; пакет подключается в контейнер одной строкой монтирования в `docker-compose.yml`, так же как ядро переговоров `negotiation_mvp`. Команда уже запускает игру в локальном docker с примонтированными пакетами, и оркестратор игры сам импортирует ядро из репо, поэтому вставка кода компонента в genaiflow.ru, ради которой задумывалась сборка одного файла (ADR-0002), не даёт выигрыша, а лишний шаг сборки и отличие от командного стиля остаются.
