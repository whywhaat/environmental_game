# Последствия считает детерминированная модель, LLM только пересказывает

Состояние города N через 10 лет после протокола рассчитывает детерминированная модель по реестру обязательств и голосам. Исход выбирается правилами из заготовленного списка, а LLM лишь пишет по нему текст и чисел не меняет. Так прогноз воспроизводим (сравнение запусков, критерий 7), объясним по шагам (критерий 6) и не выдумывает фактов. Свободный LLM-прогноз по долям, как в компоненте `ContractPredict`, отвергнут: два запуска на одном протоколе дают разный текст, и нельзя показать, откуда взялся вывод.
