# Схемы и правила переговоров отделены от адаптера Langflow

Исходники основной игры находятся в `negotiation_game/`: `schemas.py` задаёт
структурированный ответ игрока, `rules.py` проверяет и подготавливает ход на копии
состояния, `report.py` формирует отчёт, историю, проект протокола и текстовые сводки,
`run_store.py` сохраняет прогресс, `langflow_component.py` управляет этапами и интеграцией с Langflow.
Промпты, RAG и вызовы моделей пока остаются в адаптере. Функции представления
читают данные игры и возвращают строки, не меняя состояние и не вызывая модели.

`python -m negotiation_game.build_component` встраивает модули в один переносимый
`langflow/custom_components/my_components/dialog.py` и обновляет код узла в обоих
JSON flow. Собранный компонент не импортирует локальный пакет: как и для модели
последствий (ADR-0004), это сохраняет переносимость графа на платформу без файлов
репозитория. Ручные изменения собранного файла будут потеряны при пересборке.

Класс компонента называется `NegotiationGame`, тип узла и его ID в обоих графах
обновлены согласованно (`NegotiationGame`, `NegotiationGame-main`). Формат результата,
игровые правила и порядок ходов этим изменением не меняются.

## Отмена, таймауты и промежуточный отчёт

Точка входа и сетевые вызовы асинхронные, поэтому отмена задачи LF прекращает
ожидание и не запускает следующие ходы и повторы. Уже принятый удалённым сервером
запрос этим не отзывается. Скрытые SDK-повторы ChatOpenAI отключены в копиях клиентов.
По умолчанию запрос ограничен 60 секундами, сетевой сбой допускает две попытки,
вся игра ограничена 900 секундами. Лимиты задаются входами узла.

После каждого хода сохраняются `result.json` и `result.md` в отдельном каталоге
запуска. Корень — `NEGOTIATION_GAMES_DIR` или `games/` относительно каталога процесса LF.
Каждый файл заменяется атомарно. Статусы: `running`, `completed`, `failed`, `cancelled`.
При сетевой ошибке возвращается частичный результат для ReportController. При отмене
сохраняется отчёт и повторно выбрасывается CancelledError: отменённый граф не обязан
выполнять следующие узлы. Незавершённая игра не считается отклонённым протоколом
и не передаётся в расчёт последствий как завершённая.
