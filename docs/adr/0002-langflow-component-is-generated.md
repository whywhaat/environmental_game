# Компонент модели последствий для Langflow собирается из ядра

Модель последствий пишется как ядро на чистом Python без зависимостей, а файл Langflow-компонента генерирует скрипт сборки: он встраивает ядро, каталог исходов и правила в один самодостаточный файл. Собранный файл руками не правят: правки вносят в ядро и пересобирают. Так компонент работает и в локальном docker команды (контейнер видит только папку компонентов и `config/`), и на genaiflow.ru, где код компонента вставляют в интерфейс, а при переезде с Langflow на свою платформу ядро переносится без изменений.

## Considered Options

- Ядро отдельным пакетом и строка монтирования в общем `docker-compose.yml`: требует правки чужого файла и не работает на genaiflow.ru.
- Писать сразу как Langflow-компонент: при переезде логику пришлось бы вынимать из обёртки.
