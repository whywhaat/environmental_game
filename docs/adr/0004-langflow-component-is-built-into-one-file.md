# Компонент модели последствий собирается в один файл

Langflow-компонент модели последствий — один самодостаточный файл, который скрипт `python -m consequences_model.build_component` собирает из пакета `consequences_model`; руками его не правят, тест сверяет его с пакетом. Причина — genaiflow.ru: в JSON flow хранится только код узла, а пакеты из репо на платформу не попадают, поэтому тонкий компонент с импортом пакета (ADR-0003) там падает на импорте. Собранный файл работает и в docker команды без строки монтирования в общем `docker-compose.yml`, и на genaiflow; пакет остаётся источником правды и переносится на свою платформу без изменений. Это возвращает подход ADR-0002.
