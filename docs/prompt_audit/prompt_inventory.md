### Наследование и связанные документы

Для всех ролей цепочка Python: `participant_system` + Human(`role_*` из profile.prompt + `_render_profile` + `_render_other_speeches` + ответ личного секретаря + action instruction). Перед этим секретарь получает `secretary_system` + Human(`role_prompt`, экономический профиль, intent, вручную переданные rules, ledger, полную историю, блок вопросов, RAG, remaining_actions). Собственный профиль не заменяется профилем другой роли; история содержит только публично произнесённое.

REPORT использует `report` и во втором круге `report_final_round`; QUESTION — `question` + выбранную строку `question_focus`; ANSWER — `answer`; PLEDGE — `pledge`; VOTE — `vote`. `judge_system` общий для `judge_speech/review/transition`, с добавлением `judge_instruction` или UI override и записки `judge_secretary_brief`. Это разные задачи, хотя модель общая. `judge_events` содержит open_round, give_floor, invite_pledges, correct_funding, announce_pledges, second_round, start_vote, correct_vote, final_decision; second_round/start_vote не вызываются через judge_event в текущем run_chat, announce_pledges используется только отдельным announce.

Связанные документы: для всех C — [DOD_session](../DOD_session.md), [DOD_protocol](../DOD_protocol.md) и [решения о согласованности](../agent_consistency/decision_register.yaml); для meeting/действий — [игровая конфигурация](../../ecological_simulator_knowledge/04_game_rules/game_config.yaml); для judge — [инструкции судьи](../../ecological_simulator_knowledge/03_judge/judge_instructions.md) и [компактный J-свод](../../rag_docs_gorod_N/07_judge_rules.md); для RAG — [политика корпуса](../../ecological_simulator_knowledge/07_customer_methodology/rag_fragment_policy.md). ## Сводка подтверждения использования

- **29 из 38** ключей config имеют прямой маршрут чтения в прикладном Python, включая условные/default-ветки. **9** не имеют автоматического обращения прикладного загрузчика: пять role_*, три flow_* и meeting_rules. Наличие совпадающей сохранённой копии отмечено отдельно.
