# База знаний «Город N»: структура и загрузка

Редакция пакета 0.1.1 от 11.11.2026. Номер редакции обозначает версию текстов. Проект регламента судьи ожидает отдельного решения по пилоту. Документы собраны из двух источников заказчика: методички «Игра „Экологическая ситуация в городе N“» и учебного пособия «Устойчивое развитие: системный подход» под ред. Т. А. Орешкиной (2026, раздел 3.1).

По решениям, согласованным в переписке проекта к 11.11.2026, согласованные правила онлайн-игры приведены в F-14 (допуск и голосование) и F-15 (результат). Эти уточнения не меняют статус предложенного регламента ИИ-судьи.

## Как загружать

1. **Общая область нужна обязательно.** Без неё каждой роли пришлось бы дублировать факты, и версии фактов разъедутся.
2. **Одна коллекция с фильтром удобнее трёх отдельных.** Каждому фрагменту присваивается метаданное `audience` из шапки файла. Агент роли ищет только по фрагментам, где есть его роль, а судья — по всем. Так холдинг не увидит приватную инструкцию жителей, а судья видит всё и может проверить лимиты.
3. **Резать по заголовкам `##`.** Один фрагмент = один номер (F-xx, ADM-xx, J-xx…), Длину определяет содержание раздела; короткий раздел сохраняет собственный ID. При индексации сохранять версию пакета, источник, область доступа и ID. Оговорки об области применения и статусе проверки передавать вместе с текстом. Номер фрагмента сохранять в метаданных, чтобы агент и судья на него ссылались.
4. **Числа запуска в базу не класть.** Смета, бюджеты, индивидуальные пределы сторон меняются от запуска к запуску и живут в карточке роли или в `params.json`. В базе только правила и факты, которые не меняются.

## Что проверить команде

- Инструкции ролей описывают, что роль может и чего не может. Цифры лимитов — в карточке. Если в промптах уже есть другие формулировки, сверьте их, чтобы не было противоречий.
- В J-02 согласованию подлежит обязанность после отказа дать встречное предложение или объяснение. Для онлайн-игры уже согласованы финансовый допуск от 80% включительно и большинство не менее трёх голосов из пяти (F-14).
- Для ответа о действующей норме нужны официальный текст, применимая редакция и дата проверки (J-10). В архиве приведён только библиографический ориентир.
