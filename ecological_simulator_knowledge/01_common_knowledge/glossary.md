# Глоссарий и единые обозначения

| Термин | Значение в пакете |
|---|---|
| Факт сценария | Условие из задания; не доказательство реального события |
| Игровое допущение | Предложение аналитика, требующее согласования |
| Подтверждённый ресурс | Ресурс с владельцем, лимитом, назначением и мандатом |
| Условное обязательство | Вступает в действие после явно заданного подтверждения |
| Ход | Одно завершённое сообщение одного участника в раунде 2 |
| Цикл | По одному слоту всех пяти участников |
| Протокол | Версионная фиксация учебных договорённостей |
| Концессия | Самостоятельный механизм по 115-ФЗ; не тождественен 224-ФЗ |
| ГЧП/МЧП по 224-ФЗ | Механизм с собственными требованиями к объекту, сторонам и процедуре |
| Общественные обсуждения | Процедура участия, применимость которой зависит от проекта и права |
| Мониторинг | Повторяемые наблюдения с описанной методикой; не автоматическое доказательство причинности |
| Игровая единица, ИЕ | Условная ресурсная единица, не рубль |
| Красная линия | Условие отказа конкретного агента; само по себе не общий запрет |
| Блокирующее нарушение | Дефект, не позволяющий допустить текущую версию к голосованию |
| ТРЕБУЕТ СОГЛАСОВАНИЯ | Данные или проектное решение ещё не подтверждены заказчиком |
## Пример употребления
«Одобрено 3/5» означает принятие учебного протокола после проверки судьи. Это не получение разрешения, субсидии, тарифа или государственного контракта.
