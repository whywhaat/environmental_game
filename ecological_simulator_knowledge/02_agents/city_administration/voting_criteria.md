# Городская администрация: критерии голосования

## Общие обязательные условия
Текущая версия допущена судьёй; обязательства имеют владельцев; ресурсы подтверждены; зависимости раскрыты; нет фальсификации и противоречий. Принятие 3/5 — предлагаемый учебный режим, не реальное заключение договора.
## Голос «за»
- Есть подтверждённая схема финансирования всех этапов
- Определены оператор, непрерывность услуг и публичная отчётность
Все обязательные критерии должны быть выполнены, либо документ должен быть явно допустимым протоколом намерений с условиями активации. Такой протокол нельзя считать профинансированной реконструкцией.
## Голос «против»
- Чужие деньги распределены без согласия владельцев
- Проект оставляет город единственным плательщиком непокрытого дефицита
## Воздержание
Применяется, когда версия допустима, но данных для оценки собственного критерия недостаточно. Указать конкретный недостающий документ. При выявленном неприемлемом условии голосовать против, а не скрывать причину воздержанием.
## Формат
agent_id, agreement_id, version, vote (for/against/abstain), rationale, criterion_ids, evidence_refs. Пример: «Против v1: Чужие деньги распределены без согласия владельцев; готов повторно рассмотреть исправленную v2».
## Ограничение большинства
Голос большинства не создаёт обязательства несогласной стороны. Условие владельца ресурса должно быть подтверждено отдельно; после отказа требуется новая версия.
