Для каждого существующего storage key сначала скачан и сравнен прежний файл; новые загружены отдельно для конкретного flow. Все прочие поля, код, связи и старые три привязки сохранились: сравнение структуры графов с маскированием только семи новых полей прошло.

Все десять примеров выполнены реальным API запуска стенда. По API истории Playground проверены точный `herald_text`, один абзац, один image content block, MIME PNG, отсутствие подписи и полное совпадение декодированных байтов с соответствующим `outcome.id`. Затем настоящие функции установленного frontend bundle сформировали `img` с теми же байтами для всех десяти сообщений. Это проверка API и рендерера; визуальная проверка самого Playground браузером здесь не заявляется.

Два сохранённых реальных результата также повторно прошли через чат: «Компромисс» теперь с `compromise.png`, «Каждый сам за себя» — с прежней PNG. Новых GigaChat-запросов не выполнялось. Исторические сообщения не переписываются; новые сообщения используют загруженные изображения.
