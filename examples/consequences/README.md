# Стенд модели последствий: 10 проверочных исходов

Это синтетические итоги в формате `Data.data` оркестратора Влада, а не сыгранные партии. Они демонстрируют существующую модель последствий независимо от готовности игры. Здесь нет переговоров, LLM и API-ключей; исход каждый раз заново рассчитывается по выбранному JSON, а не подставляется готовой газетой.

## Проверка в Langflow

Импортируйте [Consequences_demo.json](../../langflow/Consequences_demo.json), откройте Playground и отправьте номер, название или id исхода. Например: `1`, `Открытая река`, `open_river`. Регистр и пробелы по краям не важны. Пустой ввод выбирает первый пример; неверный выбор показывает ошибку со списком вариантов.

В чате появляется газета одним связным абзацем от отправителя «Вестник · проверочный пример». На выходах узла «Модель последствий» также доступны подробный отчёт с объяснением, структурированный прогноз и промпт «Вестника».

| Номер | Исход и входной JSON | Протокол | Исполнение взносов по модели | Ввод очистных |
| --- | --- | --- | --- | --- |

| 2 | [Недострой](nedostroy.json) | принят | 185 млн ₽ | не введены за 10 лет |
| 3 | [Решили без жителей](without_residents.json) | принят | 270 млн ₽ | 36-й месяц |

Во всех примерах смета и заявленные взносы составляют 270 млн ₽. Различаются голоса, распределение взносов и условия протокола, поэтому исполнение и состояние города разные. Некоторые примеры включают кредит: это предусмотрено текущими правилами модели.

Числа в таблице — контрольные значения текущей учебной модели, не прогноз по реальной реке. Достижимость всех 10 исходов проверяется тестами; содержательную обоснованность правил и порогов нужно согласовать с преподавателем.

## Иллюстрации

На текущем локальном стенде подключены изображения для всех десяти примеров. Отправьте номер `1`–`10` в Playground: каждый исход возвращает своё изображение и текст одним абзацем. Набор 10/10 также подключён к интеграционной игре и повтору сохранённых реальных партий.

В узле «Модель последствий» загрузите рисунки в поля соответствующих исходов. Инструкция и референс — [assets/consequences](../../assets/consequences/README.md). Без нужного рисунка остаётся читаемый текст; иллюстрация другого исхода не подставляется.

Экспорт flow содержит код и проверочные данные, но не загруженные изображения. На другом сервере рисунки нужно загрузить заново. Встроенный компонент не требует установки локального пакета проекта.

## Проверка без Langflow

Те же файлы можно передать в публичный CLI модели:

```bash
python -m consequences_model examples/consequences/open_river.json
python -m consequences_model examples/consequences/each_for_self.json --json
```

Для команды ядра эти JSON служат примерами структуры входа. Модель читает готовый итог; определение голосов и принятия протокола остаётся за оркестратором. Текущий формат описан в [.scratch/consequences-model/vlad-game.md](../../.scratch/consequences-model/vlad-game.md).

## Пересборка

После изменения модели или примеров:

```bash
python -m consequences_model.build_component
uv run --no-project --python 3.12 --with 'lfx==1.12.5' python -m consequences_model.build_flow
uv run --no-project --python 3.12 --with 'lfx==1.12.5' python -m consequences_model.build_demo
python -m unittest discover -s tests
```

Номера задаются порядком [manifest.json](manifest.json). Файлы примеров и встроенный код узла выбора сверяются тестами; сборщики не изменяют исходный flow команды.
