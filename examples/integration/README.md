# Итоги двух реальных партий

03.11.2026 локально выполнены две партии игры из `Vlad's_branch` на коммите [`10a5c689ef8748f64418702b41d7ce917349da23`](https://github.com/whywhaat/environmental_game/tree/10a5c689ef8748f64418702b41d7ce917349da23). Использовались Langflow/lfx 1.12.5 и настоящие ответы GigaChat пяти ролей и LLM-парсера; ключ и код ядра в пакет не входят. Для короткой проверки выбраны пять ходов торга вместо пятнадцати, затем ядро выполнило Last Call и голосование. Код исходных компонентов игры не изменялся.

| [vlad_10a5c68_accepted.json](vlad_10a5c68_accepted.json) | Исходные стратегии ветки | 5 за | Да | 260 из 270 млн ₽ | 260 млн ₽ | `compromise` | 60-й месяц |
| [vlad_10a5c68_rejected.json](vlad_10a5c68_rejected.json) | К стратегиям администрации, жителей и НКО добавлена жёсткая позиция голосовать против | 2 за, 3 против | Нет | 230 из 270 млн ₽ | 115 млн ₽ | `each_for_self` | Не введены за 10 лет |

Это компактные проекции сохранённых результатов `TwoLLMContractGame.result.data`, а не вручную составленные протоколы. Сохранены исходные значения профилей (`id`, `name`, `budget`, `money`), числовые сведения `state.players`, условия `state.levers`, смета, суммы, голоса и итоговые флаги. Удалены история, промпты и стратегии, комментарии голосующих, RAG-контекст, отладка и готовые тексты ядра. Полный результат `forecast` на каждой проекции сравнен с результатом на сыром JSON и совпал; предупреждений нет. Голоса и числовые значения не подменялись. Тесты распакованного пакета проверяют ожидаемые последствия обеих партий.

В этой версии ядро принимает протокол по большинству голосов, даже при дефиците. Поэтому в первом примере одновременно `consensus_reached: true` и `budget_closed: false`. Модель последствий использует решение ядра; недостающие деньги автоматически не добавляет. Эти две короткие партии проверяют совместимость формата, а не все стратегии игры.

Из корня распакованного пакета, без Langflow, сети и API-ключей:

```bash
python -m consequences_model examples/integration/vlad_10a5c68_accepted.json --json
python -m consequences_model examples/integration/vlad_10a5c68_rejected.json --json
```

Для игрока используйте `herald_text`. Общий формат описан в [инструкции подключения](../../docs/consequences-integration.md). Десять синтетических примеров стенда находятся отдельно в `examples/consequences/`.
